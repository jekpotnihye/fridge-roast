# Fridge Roast: One Line, Biggest Laugh

An entry for the [Fridge Roast: One Line, Biggest Laugh](https://make.fun/bounty/u-gentle-badger-68-fridge-roast-one-line-biggest-laugh-a7c354bb)
competition on make.fun: one line roasting a smart fridge, written by a
program to `/output/entry.txt`.

## The line

> My fridge's ice maker rations one cube: cold's a subscription, and I'm on the free trial.

## Run it

```sh
python3 main.py
```

`main.py` checks the line is 1 to 200 characters, writes it to
`/output/entry.txt` (override with `OUTPUT_PATH` for a local run), and
prints it with its character count.
